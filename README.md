# Can Yıldırım — Kişisel Portfolyo, Hizmet & Pazarlama Web Sitesi

## 🌟 Öne Çıkan Özellikler

1. **Hero Section:**
   - Dikkat çekici *"Karmaşık Problemlere Modern Yazılım Çözümleri"* başlığı
   - Can Yıldırım'ın C#, Web ve Veritabanı uzmanlıklarını vurgulayan 2 cümlelik profesyonel özet
   - 2 Adet Net CTA Butonu: *"Projelerimi İncele"* ve *"Benimle İletişime Geç"*
   - Güven metrikleri (5+ Yıl Tecrübe, 30+ Proje, %100 Memnuniyet, 7/24 Destek)
   - C# mimarisi odaklı interaktif kod penceresi vitrini

2. **Hizmetlerim & Uzmanlık Alanları (Armut / Freelance Standartlarında):**
   - Web Geliştirme (Mobil uyumlu, hızlı, SaaS ve kurumsal)
   - Masaüstü Uygulamaları & C# (.NET Core, WinForms, WPF, Stok/POS Otomasyonu)
   - Veritabanı Mimarisi & MySQL (Optimizasyon, veri modelleme, yedekleme)
   - Özel Yazılım & Süreç Otomasyonu (Scraping, Botlar, REST API köprüleri)
   - Her hizmet kartından doğrudan ilgili hizmeti seçip iletişim formuna aktaran **"Bu Hizmet İçin Teklif Al"** akıllı butonu

3. **Projelerim (Portfolio / Case Studies):**
   - Kategori filtreleme butonları (*Tümü, C# & Masaüstü, Web Geliştirme, Veritabanı & API*)
   - Gerçekçi mockup başlıkları, detaylı açıklamalar, teknoloji etiketleri
   - *"Canlı Önizleme"* ve *"GitHub"* butonları

4. **Hakkımda & Yetenekler:**
   - Can Yıldırım'ın yazılım felsefesi ve iş ahlakı
   - C#, MySQL, JavaScript, Tailwind, .NET, REST API, Git vb. teknoloji rozetleri
   - 4 Temel Güven İlkesi: Zamanında Teslimat, Temiz & Modüler Mimari, Şeffaf İletişim, Satış Sonrası Destek

5. **Blog & Teknik Rehberler:**
   - C# mimarisi, MySQL sorgu optimizasyonu ve web dönüşüm stratejileri üzerine makaleler
   - **Sayfa içi Makale Okuma Modalı** (Devamını Oku butonuna basıldığında açılan popup)

6. **İletişim & Teklif Formu (Conversion Hub) & Footer:**
   - Ad, E-posta, Telefon, Hizmet Seçimi, Bütçe ve Mesaj alanları
   - Form doğrulama, buton yüklenme animasyonu ve şık **Toast Bildirimi**
   - Doğrudan E-posta, WhatsApp, Konum ve Armut/LinkedIn profili bağlantıları
   - Başa Dön (Back to Top) kayan butonu

## 🚀 Nasıl Çalıştırılır?

1. Herhangi bir ekstra kurulum (Node.js, npm vb.) gerekmez!
2. `index.html` dosyasına çift tıklayarak doğrudan Chrome, Edge, Safari veya Firefox üzerinde açabilirsiniz.
3. Ya da VS Code kullanıyorsanız `Live Server` eklentisi ile tek tıkla çalıştırabilirsiniz.
4. Python ile yerel sunucuda test etmek için:
   ```bash
   python -m http.server 8000
   ```
   ve ardından tarayıcınızda `http://localhost:8000` adresine gidin.
